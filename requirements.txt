## Installation

### Quick Install

# Quick install command
# pip install -r requirements.txt


### Development Install

# Development install command
# pip install -r requirements-dev.txt


### From Individual Groups

# Examples:
# pip install pytest==8.3.2 pytest-xdist==3.8.0 playwright==1.40.0
# pip install allure-pytest==2.13.5 pytest-html==4.1.1
# pip install pylint flake8 black bandit


## Environment Setup

### 1. Create Virtual Environment

# Create virtual environment (example)
# python -m venv venv
# source venv/bin/activate  # Linux/Mac
# venv\Scripts\activate     # Windows


### 2. Upgrade pip

# Upgrade pip command
# python -m pip install --upgrade pip


### 3. Install Requirements

# pip install -r requirements.txt


### 4. Install Playwright Browsers

# Playwright browser install
# playwright install chromium


### 5. Verify Installation

# Verify installation
# pytest --version
# playwright --version
# python -c "import allure_pytest; print('OK')"


## Version Constraints

### Python Versions

# - Minimum: 3.11
# - Tested: 3.11, 3.12
# - Recommended: 3.12.10 (current)

### Browser Support

# - Chromium: Latest
# - Firefox: Optional (playwright install firefox)
# - Safari: macOS only (playwright install webkit)

### OS Support

# - Linux (Ubuntu, Debian, CentOS)
# - Windows 10/11
# - macOS 10.15+

## Troubleshooting

### pip SSL Error

# pip SSL workaround
# pip install --trusted-host pypi.python.org -r requirements.txt


### Playwright Installation Issues

# Playwright install troubleshooting
# playwright install chromium --with-deps
# For Linux missing dependencies
# sudo apt-get install -y libgconf-2-4 libdbus-1-3


### Version Conflicts

# Version conflict troubleshooting (example steps)

# rm -rf venv
# python -m venv venv
# source venv/bin/activate
# pip install -r requirements.txt
